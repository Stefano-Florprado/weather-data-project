Descrizione

Questo progetto utilizza un'API meteo per raccogliere dati in tempo reale su diverse città e salvarli in un file CSV per successive analisi.

Obiettivi
  - Imparare a usare API REST
  - Estrarre e gestire dati JSON
  - Costruire una semplice data pipeline in Python
  - Salvare dati strutturati per analisi future

Tecnologie utilizzate: Python, Requests, Pandas, OpenWeather API

Come funziona:
- L’utente inserisce una o più città
- Il programma chiama l’API meteo
- I dati vengono estratti e strutturati
- I risultati vengono salvati in un file CSV

Output

Il file meteo.csv contiene: città, temperatura, umidità, condizioni meteo, vento, timestamp
